# Duck クラウド環境の準備

関連: #155

クラウドのインストール用スクリプトは、選択済み `/workspace/CodexSkill` にある共有インストーラーを直接呼び出し、Duck のルートと Duck が管理する設定ファイルを渡す。Duck 内に呼び出しだけを行う `tools/cloud/setup.sh` は必須にしない。

Duck はツールのバージョン、ハッシュ、検査依存、ロックファイル、ビルド対象を管理する。共有側の固定版と呼び出し方法がレビューで確定するまでは、インストール用スクリプトの差し替えを保留する。通常のタスク開始では環境準備を繰り返さない。実際の `DebugHost` 起動と全体テストは環境準備から分ける。
