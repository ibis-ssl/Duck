## 結果

- 前回指摘した `ResizeObserver + getBoundingClientRect` ベースの実装は残っていないことを確認した
- `pointer-events="none"` は transformed な `<g>` 配下の child SVG 要素へ pointer event を当てず、root `<svg>` 側の `@onmousemove` / `@onmousedown` / `@onmouseup` / `@onwheel` にイベントを固定する意図として妥当
- cursor overlay 自身も CSS 側で `pointer-events: none` になっており、overlay 表示中でも drag/pan や hover 座標更新を阻害しない
- `+X` ラベルは `text-anchor="end"` 付きで axis box 内側へ寄せられており、最新差分の範囲では追加問題は見当たらない
