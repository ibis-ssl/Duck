# TRACKER-028 evidence

## タスク

- ID: TRACKER-028
- Title: capture 1680 付近の複数 ball 再発を解析して修正する

## 原因

指定 diagnostics log の trackedFrame 1680 では、raw ball は `x=-565.1,y=1704.1` と `x=-583.6,y=1715` の近接 2 観測だった。

tracked output は `#106:x=-583.1,y=1715.1,vis=1,cams=0` と `#112:x=-383.9,y=1601.6,vis=0.75,cams=1` の 2 ball になっていた。`#112` は raw に対応する fresh ball ではなく、trackedFrame 1677 から visibility が `0.801 -> 0.784 -> 0.766 -> 0.75` と減衰している stale secondary track だった。

既存実装は secondary ball の外部出力を `ObservationCount >= 3` だけで許可していたため、一度 grown-up になった secondary track が欠測後も `BallTracker.OutputVisibilityThreshold = 0` と `TrackLifetimeNs = 1000000000` の範囲で `TrackedFrame.Balls` に残った。

## 変更

- `TrackerEngine` の secondary ball 出力条件を変更し、primary 以外は `HasFreshObservation == true` かつ `ObservationCount >= 3` の場合だけ出力するようにした。
- primary ball の短期欠測予測出力は維持した。
- 成長済み secondary が欠測直後に外部出力へ残らない regression test を追加した。
