# RAW-VISION-012 実装・検証レポート

## タスク

Diagnostics timeline に再生・停止・早送り controls を追加する。

## executor

main agent。変更範囲が `Diagnostics` page state、scrubber UI、playback index helper/test に限定され、既存 timeline selection と密結合しているため。

## 変更内容

- `/diagnostics` の scrubber 左側に再生、停止、早送り icon button を追加した。
- 通常再生は現在 entry と次 entry の timestamp 差分で 1 entry ずつ進め、実際の記録速度に合わせるようにした。長い timestamp 差分も上限 clamp なしで使う。
- 早送りは timestamp 差分を短縮した interval で 5 entry ずつ進めるようにした。
- 再生中は再生ボタンを停止ボタンへ切り替え、早送り中は早送りボタンを停止ボタンへ切り替えるようにした。
- 最後の entry に到達したら playback を停止して先頭 entry に戻し、停止操作では現在選択中 frame を維持する。
- reload / log 切替 / scrubber drag / wheel 操作では playback を停止し、選択状態の不整合を避ける。
- 停止や mode 切替の直後に遅れて到着した playback tick は、cancellation と active mode を再確認して反映しないようにした。
- `DiagnosticsPlaybackState` と `DiagnosticsPlaybackStateTests` を追加し、次 index 計算、早送り step、末尾 clamp、entry なし、末尾停止、末尾後の先頭復帰、停止済み tick / mode 切替前 tick の抑止、通常再生が timestamp 差分を上限 clamp なしで使うこと、早送り interval が timestamp 差分の 1/4 になること、早送り interval の最小値を確認した。
- `RAW-VISION-012` として `Tracker.Server/Design` の task/phase/plan を更新した。
