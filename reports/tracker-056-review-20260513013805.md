## 結果

- 結果:
  - レビュー対象は TRACKER-056 の未コミット差分に限定した。
  - `FieldSourceOptions` は `Vision Input`、ibis tracker、`External`、`Unknown`、source label を生成し、role/filter の `All` は Field source として追加していないことを確認した。
  - 既定は左 `Vision Input` / 右 ibis tracker output で、`ResetForLogChange()` だけが左右 Field source を既定へ戻し、selected entry 更新の `Load()` では選択と comparison fold state を維持することを確認した。
  - ibis tracker output は render snapshot 由来の `trackedRenderView` を使っており、tracker packet sidecar の own record 欠落に依存しないことを確認した。
  - external / unknown / source label は selected diagnostics entry の tracked frame から own snapshot timestamp を取り、TRACKER-055 の cached index 上で nearest snapshot を解決することを確認した。
  - sidecar unavailable / empty / corrupt、own baseline missing、candidate missing、drawable empty は Field source frame の status/message として返り、render snapshot がある通常画面では Field 領域を消さず status + empty canvas として扱われることを確認した。
  - source変更や selected entry 変更で sidecar JSONL 全体再読込に戻っていないことは、cache reuse test と `LoadFieldSourceFrame` の `GetOrBuildIndex` 経路で確認した。
  - `Tracker Comparison` 折り畳みは comparison panel の中身だけを隠し、左右 Field source selector は Field 見出し側に残ることを確認した。
  - focused test は `TrackerDiagnosticsComparisonViewStateTests|DiagnosticsPlaybackStateTests` で 36 passed。`git diff --check` は問題なし。
