## 指摘事項

- 指摘要約または「指摘なし」:
  - Medium: `Tracker/Tracker.Tests/Contracts/TrackerPacketGeneratorContractTests.cs:121-142` の capabilities test は `isFlying: true` と `kickedBall` を同時に持つ 1 ケースしか見ていないため、capabilities を「source implementation の固定能力」ではなく「その frame で観測された事象」に応じて動的生成する誤実装を許します。`Tracker/Tracker.Core/Design/tracker-architecture-plan.md:106-110` と `SslProto/src/external/ssl-game-controller/proto/tracker/ssl_vision_detection_tracked.proto:8-13,87-88` では capabilities は source 側の実装能力です。たとえば flying ball や active kick がない frame で `CAPABILITY_DETECT_FLYING_BALLS` / `CAPABILITY_DETECT_KICKED_BALLS` を落とす実装でも、この test 群は green のまま通ります。

## 結果

- 結果:
  - 要修正。`TRACKER-002` の exit criteria にある単位変換、primary/secondary ball 並び、`kicked_ball` 寿命、timestamp 出力の観点は test 群で概ね固定できていますが、capabilities の契約が frame 非依存の能力一覧として十分に固定されていません。
  - sub-agent 実行は 3 回試行しましたが、この環境では `codex exec` が `~/.codex/sessions` 権限エラーまたは network 制限で失敗しました。そのため report は parent が代筆しています。

- 未解決のリスクまたは後続対応:
