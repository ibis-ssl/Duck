Tracker.Server 共通 navigation の見た目を viewer UI と揃える。

## executor

main agent。変更範囲が `MainLayout` / `NavMenu` の markup と CSS に限定され、既存 viewer layout との視覚整合を確認しながら小さく調整する必要があったため。

- `NavMenu.razor` に collapsed 状態の root class を追加し、CSS isolation でも collapsed 用 styling が安定して効くようにした。
- `NavMenu.razor.css` の brand、toggle、nav item、active / hover、mobile menu toggle を viewer / diagnostics の border・background・text color 階調へ寄せた。
- collapsed sidebar では icon 中心の密な表示を維持し、mobile toggle の既存 checkbox 操作は維持した。
- review の non-blocking concern を受け、`MainLayout.razor.css` に残っていた未使用の Blazor template `.top-row` style を削除した。
- `RAW-VISION-011` として `Tracker.Server/Design` の task/phase/plan を更新した。
