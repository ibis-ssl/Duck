## 指摘事項

- Blocking normal-path problems: no findings.
- ユーザー確認が必要な capability gap:
  - live 外部 tracker 受信接続は今回対象外で、`TrackerCoordinator` から自動保存される production path は own tracker packet まで。`TrackerPacketSnapshotLogWriter.TryCapturePayload` / `CapturePacket` は external / unknown role を保存でき、後続 task の外部受信経路から接続可能な形ではある。親はこの gap を `TRACKER-045` 以降で扱う判断が必要。
- Non-blocking concerns:
  - `TrackerPacketSnapshotLogWriter.Append` は `record.EnsureSemanticSummary()` の結果をそのまま書き込むが、`EnsureSemanticSummary()` は invalid `PayloadBase64` を `FromRecord` fallback summary に変換して例外を握るため、public `Append` 経路では re-decode 不能な raw payload でも `RecordCount` に入って sidecar に保存されうる（`Tracker/Tracker.Server/Tracking/TrackerPacketSnapshotRecord.cs:81-99`、`Tracker/Tracker.Server/Tracking/TrackerPacketSnapshotLogWriter.cs:166-170`）。通常の `CapturePacket` / `TryCapturePayload` 経路は valid packet または skipped/error count を使うため今回の normal path blocker にはしないが、後続の外部受信接続が `Append` を直接使う設計なら、invalid raw を skipped/error に寄せるか `Append` を内部化する判断が必要。
  - tests は raw payload round-trip と writer metadata 更新を押さえているが、`SemanticSummary` については non-null / property shape の確認が中心で、ball / robot count、team / robot id、代表位置が decoded raw payload と一致することまでは固定していない（`Tracker/Tracker.Tests/TrackerComparisonSourceTddTests.cs:118-119`、`Tracker/Tracker.Tests/TrackerComparisonSourceTddTests.cs:163-180`）。実装上は raw payload から summary を作っているため blocker にはしないが、ユーザー懸念「比較用の元データを保持していなかったら問題」を将来変更から守るには、summary 値の assertion 追加が有効。

## 結果

- レビュー完了。
- raw payload は `PayloadBase64` として sidecar に保存され、reader で復元して `TrackerWrapperPacket` として再decode可能。
- `SemanticSummary` は production 実装上、表示用 `Summary` 文字列ではなく `TrackerWrapperPacket` raw payload 由来で ball / robot / frame / source summary を作成している。
- writer API と focused tests 上は own / external / unknown の全 role を保存対象として扱っている。
- metadata は `RecordCount`、`SkippedRecordCount`、`ErrorCount`、`TrackerSnapshotSources` を更新しており、正常保存 path と invalid payload path の focused test は通過した。
- focused test 結果: `TrackerComparisonSourceTddTests` 7 passed / 0 failed / 0 skipped。
- `git diff --check 2c6e977..HEAD`: 問題なし。
