- 指摘要約または「指摘なし」: `Medium`。`Tracker/Tracker.Core/TrackerExecutionContracts.cs:305-308` の `ShouldResetForGeometryChange` は field length / width しか比較しておらず、設計書 `Tracker/Tracker.Core/Design/tracker-architecture-plan.md:403-404` が reset 対象に含めている goal geometry change を検知できない。現状のままだと goal width / depth だけが大きく変わった更新で pending buffer clear と `GeometryReset` が発生せず、旧 geometry 世代の未確定状態を引き継いでしまう。対応する contract test も `Tracker/Tracker.Tests/Contracts/TrackerEngineTemporalContractTests.cs:390-429` で field length / width 変化しか見ておらず、この欠落を検出できない。

## 結果

- 結果: 指摘あり。targeted review の結果、`TRACKER-007` 実装は profile switch の state clear、`ResolvedBaseSettings` 適用、`ProfileSwitched` / `GeometryReset` / `WorldFrameCommitted` の publish 順、frame number continuity については概ね設計どおりで、`TrackerEngineTemporalContractTests` 15 件も再実行で通過した。一方で goal geometry change に対する `GeometryReset` 契約が未実装かつ未テストのため、このままでは task 完了扱いにしない方がよい。
