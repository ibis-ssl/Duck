## 指摘事項

- 指摘要約または「指摘なし」:
  - `Medium` `Tracker/Tracker.Core/TrackerExecutionContracts.cs:41-52,195` late packet 判定が直近 commit frame の anchor timestamp (`frameTimestampNs`) しか保持していないため、既に commit 済みの merge window 内に属する packet を後着で受けると drop されず、新しい world frame として再出力される。例えば `1.000s` と `1.015s` を同一 frame として commit した後に `1.010s` が届くと `lastCommittedDetectionTimestampNs == 1.000s` のままなので受理され、確定済み frame に属する観測が後続 flush を汚染する。
  - `Low` `Tracker/Tracker.Core/TrackerExecutionContracts.cs:133-136` `ProcessedAtNs` に local processing time ではなく `maxSeenDetectionTimestampNs` を入れており、設計書の `TrackerFrame.processed_at_ns` 契約 (`Tracker/Tracker.Core/Design/tracker-architecture-plan.md:166-168`) と一致していない。診断値が camera timestamp に引きずられ、replay や clock skew を含む入力で misleading になる。
