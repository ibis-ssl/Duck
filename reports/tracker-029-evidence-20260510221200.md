# TRACKER-029 evidence

## タスク

- ID: TRACKER-029
- Title: tracked object の小刻みな振動を抑制する

## 原因

停止または低速に近い object で raw detection が数 mm から十数 mm 程度に揺れると、既存 Kalman update がその揺れをほぼ観測値どおりに追従していた。

主因は `TrackerEngine` の観測 uncertainty と process noise のバランスだった。`GetObservedBallUncertaintyMm` / `GetObservedRobotUncertaintyMm` は設定値 `MeasurementNoise` をそのまま measurement variance として扱っていた。一方で velocity の初期分散と process noise scale が大きく、短周期の raw jitter を速度変化として学習しやすかった。

その結果、stationary に近い ball / robot の tracked 位置と速度が raw detection の小刻みな揺れに引っ張られ、表示上の振動として見えていた。

## 変更

- 観測 uncertainty を `MeasurementNoise / confidence` の二乗にし、さらに `MeasurementNoiseVarianceScale` を掛けて measurement variance として扱うようにした。
- `InitialVelocityVariance` と `KalmanProcessNoiseScale` を下げ、停止状態の短周期 jitter を速度として過剰に学習しないようにした。
- `KalmanInitialVelocityVariance`、`KalmanProcessNoiseScale`、`MeasurementNoiseVarianceScale` を profile 設定へ外出しし、`Tracker.Server/appsettings.json` から調整できるようにした。
- stationary ball / robot の raw detection が交互に揺れる regression test を追加した。
- 既存の移動速度 regression は、実装変更後も追従性を維持していることを range assertion で確認する形に調整した。
