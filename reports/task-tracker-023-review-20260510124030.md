## 指摘事項

Blocking normal-path problems:

- [High] `Tracker/Tracker.Core/TrackerExecutionContracts.cs:1339-1343` の robot gate が、予測済み状態ではなく `previousState.XMm/YMm` と観測値の距離で判定されています。設計では `Tracker/Tracker.Core/Design/tracker-architecture-plan.md:726-731` で「gate 判定は生観測との差分ではなく、予測状態に対する対応付け規則」と定義されており、ball 側は `Tracker/Tracker.Core/TrackerExecutionContracts.cs:917-925` で予測位置に対して gate しています。robot は `team + robot id` で直接対応付けるため見落としやすいですが、速度を学習済みの robot が通常フレーム間で gate 距離を超えて移動し、予測位置には一致するケースでも、現在の実装は track を再初期化して velocity / covariance を失います。これは TRACKER-023 の normal path である camera-local robot Kalman tracking を壊すため、`predictedState.XMm/YMm` を使って gate し、予測 gate が効く regression test を追加する必要があります。
