- `DiagnosticsPlaybackState.PlaybackChoices` は `等倍速`、`4x`、`16x`、`64x` を公開している。
- `等倍速` choice は `DiagnosticsPlaybackMode.Play` と `FastForwardSpeedMultiplier = null`。
- `4x` / `16x` / `64x` choice は `DiagnosticsPlaybackMode.FastForward` と該当 multiplier。
- UI は `PlaybackChoices` を `foreach` で描画し、旧 Play button / Fast forward button / speed select の構造を置き換えている。
- `StartPlaybackChoiceAsync` は FastForward choice のときだけ `fastForwardSpeedMultiplier` を更新し、`StartPlaybackAsync(choice.Mode)` を呼ぶ。
- `StartPlaybackAsync` / `RunPlaybackAsync` / `GetPlaybackInterval` / `GetNextPlaybackIndex` / `ShouldApplyTick` の既存 realtime Play、FastForward tick 非間引き、stale guard の構造は維持されている。
- saved alignment v2 / scrub / Field source / comparison の選択経路には今回差分が入っていない。
- `1x` は UI / design / README 検索で該当なし。
- 旧 `diagnostics-playback__speed` / `Fast forward speed` / `OnFastForwardSpeedChanged` は対象 UI / code から削除済み。
