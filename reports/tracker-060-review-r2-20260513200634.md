- `DiagnosticsPlaybackState.GetInterval(...)` は `Play` のみ `TimeSpan.TicksPerSecond / 30` の表示 interval を返し、`FastForward` は timestamp delta / speed multiplier / minimum interval の既存挙動を維持している。
- `Diagnostics.razor.cs` の playback loop は開始時 selected replay timeline tick の `ReceivedAt` と開始 wall-clock を保持し、各表示更新後に wall-clock から next index を再計算して `SelectTimelineByIndex` へ渡している。timer 回数分だけ1 tickずつ遅れて進む実装ではない。
- `Fast Forward` は `GetNextIndex(...)` による1 tickずつの前進を維持しており、tick 間引きに変わっていない。
- `ShouldApplyTick(...)` は cancellation、mode、speed multiplier を引き続き確認しており、Stop / mode switch / speed switch の stale tick guard は維持されている。
- `SelectTimelineByIndex(...)` は replay timeline がある場合に `SelectReplayTimelineTick(...)` を通り、`SyncComparisonState()` は `ToReplayTimelineSelection()` を渡し続ける。scrub / playback tick / Field source / comparison は selected replay timeline tick を使う既存経路を維持している。
