## 指摘事項

- blocking normal-path problems: なし。
- user-confirmation-required gaps: なし。
- non-blocking held concerns: なし。
- 指摘要約または「指摘なし」: 指摘なし。`Home.razor` は raw/tracked toggle を追加しつつ raw viewer の camera selector と tracked viewer の field/details 表示を明確に分岐しており、tracked mode では `TrackedSnapshotStore` から構築した `TrackedVisionViewState` を `VisionFieldCanvas` と `TrackedDetailsPanel` へ渡す構成になっていることを確認した（`Tracker/Tracker.Server/Components/Pages/Home.razor:13-88`）。`TrackedVisionViewState` は `TrackerFrame` から geometry・balls・team 別 robots・publish counters を viewer 用 DTO に変換し、frame 不在時は active profile と empty state を返すため、profile switch 直後の空表示経路も成立している（`Tracker/Tracker.Server/Components/Vision/TrackedVisionViewState.cs:19-60`）。ball の role 表示も `TrackerFrame.Balls[0]` が primary ball という既存契約と整合している（`Tracker/Tracker.Server/Components/Vision/TrackedDetailsPanel.razor:54-64`, `Tracker/Tracker.Core/Design/tracker-architecture-plan.md:382-383`, `Tracker/Tracker.Core/TrackerExecutionContracts.cs:258-259`）。対応 test と関連 regression suite も通過しており、`TRACKER-015` の正常系を妨げる問題は見つからなかった。
