# TRACKER-030 evidence

## タスク

- ID: TRACKER-030
- Title: Tracked field 表示を Vision field geometry と揃える

## 原因

raw Vision 画面は `SSL_GeometryFieldSize` を直接使うため、`PenaltyAreaDepth`、`PenaltyAreaWidth`、`CenterCircleRadius` を含む field geometry から fallback field line を描画できる。

tracked 画面は `TrackerGeometrySnapshot` から `SSL_GeometryFieldSize` を再構成しているが、従来の snapshot は field length / width / goal / boundary / line thickness だけを保持していた。そのため tracked view へ戻した geometry では defense area と center circle の寸法が 0 になり、`VisionFieldLines` の fallback 描画が raw Vision 画面と一致しなかった。

## 変更

- `TrackerGeometrySnapshot` に `PenaltyAreaDepthMm`、`PenaltyAreaWidthMm`、`CenterCircleRadiusMm` を追加した。
- `TrackerGeometrySnapshot` に `FieldLines` / `FieldArcs` の軽量 snapshot を追加した。
- `TrackerEngine` の geometry snapshot 作成時に SSL-Vision geometry から上記寸法と generated line / arc を保持するようにした。
- tracked view / diagnostics replay 用の `SSL_GeometryFieldSize` 再構成時に上記寸法と generated line / arc を戻すようにした。
- contract / view-state tests に、tracked field 表示で defense area と center circle 用 geometry が消えないことを固定した。
