# 名詞一覧抽出レポート

## 概要

固有名詞だけでなく、SudachiPy が `名詞` と判定した日本語語彙とカタカナ語彙を全件収集した。

この一覧はホワイトリスト追加候補を直接確定するものではない。頻出語、一般語、専門語、誤判定を分け、利用者レビューでホワイトリストまたは prh へ振り分けるための材料である。

## 成果物

- 完全な名詞一覧: `reports/doc-lint-noun-list-20260517133815.tsv`
- 要約レポート: `reports/doc-lint-noun-extraction-20260517133815.md`

TSV の列は次の通り。

```text
surface	normalized	reading	partOfSpeech	type	count	sources
```

## 抽出条件

- 入力: `npm run -s lint:md:targets` が返す 20 ファイル
- 抽出元: `/tmp/ibisduck-vocab.json`
- 対象: `type` が `japanese` または `katakana` で、`partOfSpeech` が `名詞` から始まる entry
- 除外: 英字トークンは今回の名詞一覧から除外

## ホワイトリスト検討時の扱い

- 一般語は原則として単語単体で登録しない。
- 設計上の意味が限定される語は、複合語またはフレーズで登録する。
- カタカナ語は頻出しても、`ログ`、`ファイル`、`テスト` のような汎用語は登録範囲が広すぎる可能性が高い。
- `カルマン` のような技術用語は、英字表記 `Kalman` と合わせて alias または別 entry を検討する。
- SudachiPy の固有名詞判定はそのまま信頼せず、出現元と文脈で確認する。
