# 設定合成ライブラリ

この README は設定合成ライブラリの配置案を示す設計資料です。将来はこのファイルと `Configuration.Composition.csproj` を `Configuration/Configuration.Composition/` に置きます。現段階ではプロジェクト、製品実装、NuGet パッケージを作成しません。

## 役割

ライブラリは設定文書の読込と構造解析、相対参照による部品の取り込み、子ごとの型付き引数、`CEL` 条件、循環検出、設定値の合成、採用値・出典・適用順を含む確定結果を担当します。Duck や Aspire を参照せず、Duck 固有の型変換、有効値の検証、サービスの起動を行いません。

`includes[].args` の `{ parameter: name }` は、その取り込みを記述した直近の親が宣言した引数だけを参照します。まず親の引数を解決し、その後に子の宣言済み引数名と型を照合します。祖先や兄弟の値は暗黙に継承しません。機密項目の分類前に解析、条件式の検査、引数参照、型検査が失敗した場合、診断にはエラー種別と、取得できるときの行・列番号だけを含めます。ファイル名、キー、設定原文の抜粋、条件式の文字列値はエラー、例外、ログ、標準出力に含めません。安全な行・列番号が取得できなければ、エラー種別だけを示します。

選択した部品の取り込みは記述順に深さ優先で適用します。同名・同種別の設定に同じ型・形の値が複数指定された場合、後の値を採用し、全候補と出典を結果に残します。型、形、種別の不一致と未知の構造キー、循環はエラーです。配列は全体を置き換え、要素の追加・削除や文字列埋め込みは初版に含めません。

## 結果と表示

結果は C# の構造化データとして呼出側へ返します。非機密項目は採用値、採用元、適用順、候補の一覧と出典を保持し、部品の取り込み選択・除外と条件評価も追跡できます。ライブラリは `Console` やログ出力先を呼ばず、独自の記録処理を提供しません。

Duck 側の確認コマンド `config explain` は起動せずに全非機密項目、採用値、候補、適用順、出典を表示する案です。保持した条件式、式中の文字列値、条件へ渡した値、評価結果は成功時も表示しません。出典のファイル名と位置は安全な表示情報として明示的に分類された場合だけ表示し、それ以外は表示しません。Duck 側の型が機密項目を明示し、機密値と候補値はログ・説明・エラー・保存計画に含めません。通常起動時のログ量は ROS 2 と同程度とし、全候補を自動で列挙しません。単体起動では RuntimeHost が既存の `Tracker.RuntimeHost` 分類、開発起動では AppHost が既存の `Duck.Testing.AppHost` 分類で、採用値と、分類済みの安全な出典だけを `Debug` に一度だけ記録する案です。開発時の子 RuntimeHost は同じ合成結果を記録しません。起動前の確認時は出力せず、ライブラリ自身もログを出しません。

設定は既存の `Logging:LogLevel` で選びます。通常のログは `Warning` のままにし、確認したいホストの分類だけ `Debug` にする例です。

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Warning",
      "Tracker.RuntimeHost": "Debug",
      "Duck.Testing.AppHost": "Debug"
    }
  }
}
```

## 将来のパッケージ境界確認

通常の保存計画や原文の複製は作らず、検証済み計画は実行中だけ扱う案です。秘密値が起動に必要な場合は既存の別経路と、その読み手・保存期間を確認するまで未対応とします。

NuGet 化の境界はライブラリ本体、公開 C# API、明示依存と推移依存です。依存候補を採用する前に、版、対象 .NET、利用条件、API、公開依存、評価制限を確認します。将来は利用側の試作からライブラリまたは試作パッケージを参照し、Duck と Aspire を追加参照せずに構築できることを確認します。さらに公開 API、推移依存、パッケージ内容を確認します。

この文書と設定合成の設計書は、正式な日本語文書検査と Markdown 許可語一覧の検査対象にします。ライブラリ README は必ずプロジェクトファイルと同じ `Configuration/Configuration.Composition/` に置きます。
