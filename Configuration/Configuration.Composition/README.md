# Configuration.Composition

この README は設定合成ライブラリの配置案を示す設計資料です。将来はこのファイルと `Configuration.Composition.csproj` を `Configuration/Configuration.Composition/` に置きます。現段階ではプロジェクト、製品コード、NuGet パッケージを作成しません。

## 役割

ライブラリは設定ファイルの読込と構造解析、相対 `include`、子ごとの型付き引数、CEL 条件、循環検出、設定値の合成、採用値・出典・適用順を含む確定結果を担当します。Duck や Aspire を参照せず、Duck 固有の型変換、有効値の検証、サービスの起動を行いません。

選択した `include` は記述順に深さ優先で適用します。同名・同種別の設定に同じ型・形の値が複数指定された場合、後の値を採用し、全候補と出典を結果に残します。型、形、種別の不一致と未知の構造キー、循環はエラーです。配列は全体を置き換え、要素の追加・削除や文字列埋め込みは初版に含めません。

## 結果と表示

結果は C# の構造化データとして呼出側へ返します。非機密項目は採用値、採用元、適用順、候補の一覧と出典を保持し、include の選択・除外と条件評価も追跡できます。ライブラリは `Console` やログ出力先を呼ばず、独自のトレーサーを提供しません。

Duck 側の確認コマンド `config explain` は起動せずに全非機密項目、採用値、候補、適用順、出典を表示する案です。Duck 側の型が機密項目を明示し、機密値と候補値はログ・説明・エラー・保存計画に含めません。通常起動時のログ量は ROS 2 と同程度とし、全候補を自動で列挙しません。RuntimeHost は検証後・サービス開始前、開発ランチャーは計画検証後・資源登録前に、既存 `ILogger` の `Debug` で採用値と出典を一度だけ記録する案です。既存の `Logging:LogLevel` で選択し、事前検証時には重複して出しません。ライブラリ自身はログを出しません。

## 将来のパッケージ境界確認

通常の保存計画や原文の複製は作らず、検証済み計画は実行中だけ扱う案です。秘密値が起動に必要な場合は既存の別経路と、その読み手・保存期間を確認するまで未対応とします。

NuGet 化の境界はライブラリ本体、公開 C# API、明示依存と推移依存です。依存候補を採用する前に、版、対象 .NET、ライセンス、API、公開依存、評価制限を確認します。将来はローカル consumer からライブラリまたは試作パッケージを参照し、Duck と Aspire を追加参照せずにビルドできることを確認します。さらに公開 API、推移依存、パッケージ内容を確認します。
